# 데이터 구조 설명 (data-schema)

`data/` 폴더의 JSON 3개를 읽기만 해서 정리했습니다(수정 없음). 인증키는 쓰지 않았습니다.

- "비어 있음" = 값이 없음(null)이거나 빈 글자·공백뿐인 경우입니다.
- 필드 설명은 공식 명세가 아니라 **필드 이름과 실제 값을 보고 정리한 것**입니다. 추정이 섞인 곳은 "(추정)"이라고 적었습니다.
- 샘플의 전화번호는 뒷자리를 가렸고, 긴 글은 70자에서 잘랐습니다.

| 파일 | 건수 | 만든 방법 |
|---|---|---|
| `cinemap.json` | 2,193건 | 씨네맵 API 원본(3개 항목) + 카카오로 변환한 좌표·상태 |
| `attractions.json` | 213건 | 부산명소 API 원본 그대로 |
| `restaurants.json` | 470건 | 맛집 API에서 일부 항목만 저장 + 분류 항목 4개 추가 (원본 471건 중 좌표 문제 1건 제외) |

## 4. 작품이 영화인지 드라마인지 구분하는 필드

**없음.** 작품 관련 필드는 작품명(`opusNm`) 하나뿐입니다. 이름만으로는 구분할 수 없습니다(예: "넷플릭스 굿뉴스"는 작품명에 플랫폼 이름이 붙어 있을 뿐 영화인지 드라마인지 알 수 없음). 같은 부산영상위원회가 제공하는 "영화 속 부산정보"(공공데이터 15164328)에 개봉일 정보가 있다고 안내되어 있지만 **호출해 보지 않아 확인 못함**.

## 5. 촬영지 상세 화면에 보여줄 만한 항목

| 항목 | 있는지 |
|---|---|
| 장면 설명 | 없음 |
| 이미지 | 없음 (이미지 주소는 부산명소·맛집에만 있음) |
| 개봉연도 | 없음 |
| 감독·출연 | 없음 |
| 있는 것 | 작품명, 장소명, 도로명주소, (변환한) 좌표뿐 |

촬영지 상세 화면에 쓸 수 있는 정보는 "작품명 + 장소명 + 주소 + 지도 위치"가 전부입니다. 나머지는 다른 데이터를 붙이거나 직접 입력해야 합니다. (씨네맵 API가 응답하는 항목이 이 3개뿐이라는 것은 처음 점검 때 확인했습니다.)
