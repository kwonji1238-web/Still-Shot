## 1. 서비스 요약과 원칙

- 한 줄: 영화·드라마 속 촬영지를 지도에서 찾고, 원하면 근처 관광지·식당·카페까지 코스로 이어 보는 서비스
- 대표 사용자: "여기서 찍었다는데 바람 쐬러 가볼까? 근처에 뭐 할 거 있나?" 하는 가벼운 나들이 (여행 계획 시점이 대표, 영화를 본 직후는 진입 경로)
- 원칙 1: 촬영지를 먼저 보여준다. 코스는 촬영지 흐름에서 자연스럽게 이어지는 선택 기능이고, 필수 단계가 아니다
- 원칙 2: 막다른 길을 만들지 않는다. 결과가 없거나 좌표가 없어도 다음에 갈 곳을 남긴다
- 원칙 3: 데이터가 없어도 화면이 성립한다. 없는 칸은 비워 두지 않고 빠진다
- 범위는 영화·드라마 모두 포함, 비전은 전국. 지금 데이터가 부산광역시 공공데이터라서 생긴 제약이고, 화면 문구에 지역명을 쓰지 않는다(출처 문구 제외)

## 3. 공통 규칙

**레이아웃**
- 모바일 기준 폭 390px, 세로로 스크롤. 누르는 영역은 최소 44px
- 목록 줄은 최소 높이 64px(근처 미리보기 줄은 72px, 썸네일 56px). 주요 버튼 높이 52px, 칩 높이 44px
- 화면 위 왼쪽에 뒤로 가기(원형 44px 버튼 또는 상단바 화살표)

**번호와 핀**
- 목록 번호 = 지도 핀 번호. 번호가 같으면 같은 촬영지다
- 좌표 없는 촬영지는 번호 대신 점선 원 "–" + "주소만 표시" 라벨, 목록 맨 뒤
- 근처 장소 핀(S2·PC 지도)은 번호가 없는 작은 핀 + 이름표로 촬영지 번호 핀과 구분한다 [제안]. 코스 경로 지도(S4)의 핀 번호는 코스 카드 번호다
- 선택된 핀은 파란색(accent)으로 더 크게 + 이름표. 와이어프레임의 원형 번호 뱃지는 임시이고, 네이밍 문서의 "스틸컷 프레임 모양 뱃지"를 v0 목록 번호에 먼저 적용하고 v1에서 지도 핀으로 확장하는 것을 제안

## 4. 화면별 명세

### S1 홈 · 작품 검색
위에서 아래로
1. 상단: [서비스 이름](왼쪽, 보조색)
2. 큰 문구(2줄, 28px)
3. 검색창(높이 56px, 검정 테두리 2px, 오른쪽 검색 아이콘 버튼). 안내 문구는 위 표 참고
4. "요즘 뜨는 촬영지" 소제목 + 목록 2줄: 파인: 촌뜨기들 / 서울의 봄. 한 줄 = 작품명(16px 굵게) + "촬영지 [N]곳"(13px 보조색) + 오른쪽 화살표

동작
- 입력하면 같은 화면 아래에 일치하는 작품이 뜬다(E1). 별도 결과 화면은 없다
- "요즘 뜨는 촬영지" 줄을 누르면 검색 없이 그 작품의 S2로 간다
- 이 목록은 팀이 고른 작품 2편의 고정 목록이다. 인기·검색량 데이터는 쓰지 않는다
- 두 작품이 촬영지 데이터에 있는지는 확인 전이다. 데이터에 없는 작품은 목록에서 뺀다

### E1 검색 중 (자동완성)
- 입력창은 홈과 같은 자리·같은 높이(56px)를 유지하고, 오른쪽에 "취소" 텍스트 버튼이 나타난다. 서비스명 줄과 대표 카피도 그대로 두고, 일치하는 작품 목록이 검색창 아래에 뜬다 (2026-10-30 사용자 결정. 위쪽 영역이 남아 있어 키보드 위로 보이는 줄 수는 이전 안보다 적다)
- "일치하는 작품" 목록. 한 줄 = 작품명(일치한 글자는 굵게) + "촬영지 [N]곳". 누르면 S2
- 정렬: 앞부분이 일치하는 작품을 위로. 가능성이 높은 작품이 위쪽 몇 줄 안에 오게 한다(키보드가 아래를 가려 보이는 줄 수가 적음)
- 띄어쓰기는 무시하고 부분 일치로 찾는다 [제안]
- "취소"는 입력을 지우고 홈으로 돌아간다. 키보드는 와이어프레임에 그리지 않았다

### E2 검색 결과 없음
- 같은 입력창 + 취소
- 안내: 제목(18px 굵게) + 두 줄 설명. 원인을 하나로 단정하지 않고 오타와 정보 없음 둘 다 말한다
- 막다른 길 방지: 홈과 같은 "요즘 뜨는 촬영지" 2줄을 다시 보여준다

### S2 지도 + 작품·촬영지 시트 (반 열림, 기본)
구성
- 전체 화면이 지도. 왼쪽 위 뒤로 가기(→ S1) (지도 위에 작품명은 두지 않는다, 2026-10-30 사용자 결정)
- 지도 위 핀: 번호 원 32px(검정). 선택된 핀은 40px 파랑 + 이름표
- 아래 시트(둥근 모서리 20px, 위쪽 손잡이 36×4px)
  - 머리말(3단계 모두 고정): 포스터 칸 64×92px + [작품명](20px 굵게) + [개봉연도] · [장르](점선 라벨) + "촬영지 [N]곳"(파랑, 핀 아이콘) + 오른쪽 펼침/접기 화살표 버튼
  - 목록: 번호 + [촬영지명] + [주소] + 오른쪽 화살표. 4줄 안팎, 좌표 없는 촬영지는 맨 뒤

시트 3단계 (높이는 844px 화면 기준)
| 단계 | 시트 위치와 높이 | 보이는 것 |
| --- | --- | --- |
| 접힘 | 위 708px, 높이 136px | 머리말만 (지도 최대) |
| 반 열림(기본) | 위 440px, 높이 404px | 머리말 + 목록 4줄 안팎 |
| 펼침 | 위 104px, 높이 740px | 머리말 고정 + 아래 스크롤(줄거리 → 목록 → 출처) |

동작
- 작품을 고르면 지도가 먼저 보이고, 시트를 뺀 지도 영역 안에 모든 핀이 들어오도록 확대 수준을 맞춘다
- 시트는 손잡이를 끄는 것과 별개로 머리말 버튼으로도 단계를 바꾼다
- 핀을 누르면 해당 줄이 강조되고(핀 쪽으로 지도 이동), 모바일에서 줄 본문을 누르면 같은 동작(그 핀으로 확대, 줄 강조, 펼침 시트는 반 열림으로 내림)이고 줄 오른쪽 화살표(44px)를 누르면 S3로 간다(2026-10-30 사용자 결정). 핀이 없는 촬영지 줄은 줄 전체가 E3로 간다. PC는 줄을 누르면 상세 패널이 열린다
- 촬영지를 선택하면(핀을 누르거나 S3의 "지도로 보기"로 들어올 때) 그 촬영지의 근처 장소 핀이 지도에 따로 뜬다. 후보는 S3의 "근처에 이런 곳"과 같다(관광지 최대 2 + 식당 최대 1). 번호 없는 작은 핀 + 이름표 [제안]. 눌러도 이동하지 않는다 [제안]. 다른 촬영지를 고르면 그 촬영지의 근처 핀으로 바뀐다. 후보가 없거나 좌표 없는 촬영지(E3)면 핀이 없다. 선택한 촬영지와 근처 핀이 함께 보이도록 확대 수준을 맞춘다 [제안]
- 접힘 상태에서 핀을 누르면 시트가 반 열림까지 자동으로 올라와 해당 줄을 강조한다 [제안]
- 작품 정보 배치(2026-10-30 사용자 결정): 포스터 옆 칸에 작품명(1줄)을 맨 위에, 촬영지 N곳 / 개봉연도 · 장르 / 출연(1줄)을 한 묶음(줄 간격 2px)으로 포스터 맨 아래에 맞춰 둔다. 칸 전체가 포스터 높이(92px)를 넘지 않는다. 줄거리는 포스터 아래 전체 폭으로 쓴다(3줄). 접힘에서는 작품명·촬영지 수만 남긴다. 값이 없는 줄은 빠진다.
- 말줄임 글(출연·줄거리·S5 소개)은 누르면 전체가 펼쳐지고 다시 누르면 접힌다. 시트 안에서 펼치면 시트도 끝까지 올라간다. 눌러서 이동하는 줄(목록 행·코스 카드)의 말줄임은 이동한 화면에서 전체가 보인다.
- 데이터 빠짐: 포스터가 없으면 아이콘 타일, 연도·장르가 없으면 그 줄만 빠지고 "작품명 + 촬영지 N곳"으로 성립
- 모든 촬영지가 좌표 없음이면 지도 없이 목록만 보여준다 [제안]

### S2 시트 펼침 (v0 화면)
- v0에서는 지도 없이 이 시트 내용만 화면 전체로 쓴다. v1에서 뒤에 지도를 깔면 같은 내용이 그대로 시트가 된다
- 위쪽에 머리말 고정, 그 아래만 스크롤: 줄거리 칸(점선, 두 줄까지 + "더 보기", 누르면 펼침) → 촬영지 목록(좌표 없는 줄은 맨 뒤) → 출처 문구
- 줄거리는 외부 작품 데이터를 연결해야 채울 수 있다. 지금 데이터에는 없으므로 없으면 칸 자체가 빠진다
- 구·군 필터 칩은 없다

### S3 촬영지 상세 (사진 있음)
위에서 아래로
1. 사진 220px(약 16:9), 왼쪽 위 원형 뒤로 가기 버튼. 사진 출처 표기는 달지 않는다
2. 작품 칩 [작품명](회색 알약, 높이 32px)
3. [촬영지명](26px 굵게)
4. 핀 아이콘 + [주소]
5. "지도로 보기" 버튼(검정 채움, 52px) → S2. v0에서는 이 자리에 "카카오맵에서 열기" 외부 링크 [제안]
6. "근처에 이런 곳" 소제목 + "촬영지에서 가까운 곳" 부제 + 3줄(관광지 2 + 식당 1). 한 줄 = 썸네일 56px + 이름 + "관광지 · 직선 [0.0]km" + 오른쪽 화살표. 줄을 누르면 S5로 간다. 사진 주소가 있으면 사진 타일, 없으면 빈 프레임 타일(관광지·식당 같음)
7. "이 근처 코스 보기" 버튼(파랑 테두리 52px, 지도 버튼보다 한 단계 약함) → S4
8. "같은 작품의 다른 촬영지" 소제목 + 칩 3개(가로 스크롤) → S3 [제안]

메모
- 첫 화면(844px)에 근처 미리보기와 코스 버튼이 들어오도록 사진 높이를 220px로 잡았다. 코스 발견율의 출발점이라서다
- 근처 미리보기 줄을 누르면 S5로 간다(2026-10-30 사용자 결정). 코스는 따로 코스 버튼으로 간다. 지도 위 근처 장소 핀은 눌러도 이동하지 않는다 [제안]
- 식당·카페도 사진 주소(작은 사진)가 있으면 사진 타일, 없으면 빈 프레임 타일로 둔다(2026-10-29 데이터 확인: 470곳 중 424곳에 있음)
- 지금 데이터에는 촬영지 사진이 없다. 이미지 주소는 나중에 따로 요청해 넣고, 그 전에는 모든 촬영지가 "사진 없음" 화면이다

### S3 사진 없음
- 사진 칸을 비워 두지 않고 없앤다. 상단은 낮은 헤더(뒤로 가기만)로 바뀌고 작품 칩·[촬영지명]·주소·지도 버튼이 위로 올라온다
- 나머지(근처에 이런 곳, 코스 버튼, 다른 촬영지 칩, 출처)는 S3와 같다

### E3 좌표 없는 촬영지 (전체의 약 5%)
- 사진이 있으면 S3처럼 상단에 사진, 없으면 S3 사진 없음처럼 사진 없이 시작한다. 사진 유무는 좌표와 별개다
- 작품 칩 + [촬영지명] + [주소] + 회색 안내 상자(이유 설명) + "주소 복사" 버튼(흰 바탕, 검정 테두리 52px)
- 지도 버튼은 없다. "근처에 이런 곳"과 "이 근처 코스 보기"도 숨긴다(좌표가 없어 거리를 못 구함). 비활성 버튼은 만들지 않는다
- 이어갈 곳은 남긴다: "같은 작품의 다른 촬영지" 칩 3개 → S3
- 와이어프레임의 주황 점선 상자("숨김 — …")는 설명용 표시라 제품에는 없다

### S4 근처 코스 (선택)
- 상단바: 뒤로 가기(→ S3) + "근처 코스"
- 제목 "[촬영지명] 근처 코스" + 부제
- 전체 경로 지도 영역(번호 핀 + 직선, 아래 메모 참고)
- 세로 타임라인: 번호 원(28px, 1번만 파랑, 나머지 검정)과 연결선, 오른쪽에 카드. 카드 전체를 누를 수 있고 오른쪽에 화살표
  1. 촬영지(칩 "촬영지" 파랑 채움 + [작품명] + [촬영지명]) → S3
  2·3. 관광지(사진 타일 56px, 칩 "관광지", "직선 [0.0]km", [관광지명]) → S5
  4. 식당(사진 타일, 사진 주소가 없으면 빈 프레임) → S5
  5. 카페(사진 타일, 사진 주소가 없으면 빈 프레임) → S5
- 맨 아래 버튼 "[작품명]의 다른 촬영지 보기"(검정 테두리 52px) → S2 (막다른 길 방지)
- 출처 문구
- 구성: 촬영지 + 관광지 최대 2 + 식당 최대 1 + 카페 최대 1. 그림은 최대 5곳인 경우다. 카페는 근처에 있을 때만 넣고, 없거나 관광지·식당이 모자라면 그 카드 자체를 만들지 않는다(빈 카드 없음)
- 순서(촬영지 → 관광지 → 식당 → 카페)는 와이어프레임의 가정이고, 실제 코스 규칙과 맞춰 확정해야 한다
- 장소별 지도 링크는 없다. 대신 제목·부제 아래, 세로 타임라인 위에 전체 경로 지도 영역을 둔다. 카드 번호와 같은 번호의 핀을 코스 순서대로 직선으로 잇고, 모든 핀이 한 화면에 들어오게 맞춘다. 선은 순서를 이은 직선이지 실제 길이나 이동 시간이 아니다. 코스 순서가 정해진 뒤(OpenAI 결과 또는 규칙 기반 대체)에 번호와 선을 그리고, 핀이 하나뿐이면 선 없이 핀만 보여 준다. 보기 전용이라 핀을 눌러도 이동하지 않는다 [제안]. 지도가 뜨지 않으면 이 영역만 빠지고 타임라인은 그대로다
- 경로 지도의 높이·핀·선 모양은 캔버스와 design.md에 없다. 제안: 높이 약 200px, 지도 핀(24px)에 카드 번호, 1px 직선 [제안]

### S5 장소 상세 (관광지)
- 사진 220px(사진 주소가 있을 때만, 왼쪽 위 뒤로 가기 → S4). 식당·카페는 작은 사진 주소(417×320)만 있어 그것을 쓰고, 사진 주소가 없으면 S3 사진 없음처럼 낮은 헤더로 시작
- 분류 칩("관광지" 등) + "[촬영지명]에서 직선 [0.0]km"
- [관광지명](26px 굵게) + [주소]
- "지도로 보기" 버튼(고스트, 2026-10-30 사용자 결정, 주소 복사 버튼은 두지 않는다). 모바일은 전체 화면 장소 지도(#/m/촬영지/장소)로 간다: 촬영지 번호 핀 + 이 장소 선택 핀(이름표)이 한 화면에 들어오고, 아래 카드에 분류·직선 거리·이름·주소가 있다. 보기 전용이고 뒤로 가기는 S5로 돌아온다. PC는 이동 없이 뒤의 지도에 이 장소 핀을 띄워 확대한다. 지도가 안 되면 버튼을 숨긴다. 코스 전체는 S4의 경로 지도에서, 근처 장소는 S2의 근처 장소 핀에서 본다
- "소개" 칸(점선): 관광지 데이터에 소개글이 있을 때만, 4줄까지 + 말줄임표. 없으면 칸 자체가 빠진다
- "[촬영지명] 보러 가기" 버튼(파랑 테두리) → S3 (막다른 길 방지)
- 출처 문구: 관광지·식당 데이터 제공처를 확인한 뒤 정한다(미정)
- 캔버스에는 관광지 버전만 그려져 있다. 식당·카페 버전은 소개글이 없어 "소개" 칸이 빠지고, 사진은 주소가 있을 때만 보인다

### PC 지도 + 작품·촬영지 목록 (768px 이상)
- 상단바: [서비스 이름] + 검색창(현재 작품명이 들어간 상태)
- 왼쪽 패널(폭 360px, 1023px 이하는 300px): 모바일 시트와 같은 내용(작품 정보 머리말 + 촬영지 목록 + 맨 아래 출처 문구). 항상 열려 있어 시트 단계가 없다
- 나머지는 지도. 모든 핀이 패널을 뺀 지도 영역 안에 들어오게 확대 수준을 맞춘다
- 목록 번호 = 핀 번호

### PC 촬영지 상세 (지도 위 상세 패널)
- 목록에서 줄을 누르거나 핀을 누르면 선택된 줄(연한 파랑 바탕)과 선택된 핀(파랑 + 이름표)이 함께 강조되고, 지도 위에 상세 패널(폭 400px, 지도 왼쪽 위 여백 16px)이 뜨고, 근처 장소 핀도 지도에 뜬다
- 패널 구성: 사진 168px(오른쪽 위 ✕) → 작품 칩 → [촬영지명] → [주소] → 근처에 이런 곳 3줄 → "이 근처 코스 보기" → 출처 문구. 사진이 없으면 사진 영역 없이 머리말부터
- ✕는 패널만 닫고 지도와 목록은 그대로 둔다(모바일의 뒤로 가기에 해당)
- "지도로 보기" 버튼과 "같은 작품의 다른 촬영지" 칩은 없다. 이미 지도와 목록이 옆에 있기 때문이다
- "이 근처 코스 보기"를 누르면 패널 내용이 S4로 바뀌고, 코스의 장소를 누르면 촬영지는 S3, 관광지·식당·카페는 S5 내용으로 바뀐다 [제안]. 코스를 열면 패널 안에는 경로 지도를 두지 않고, 메인 지도에 코스 번호 핀과 선을 겹쳐 그린다 [제안]. 이때 작품의 촬영지 번호 핀과 코스 번호가 섞이는 처리는 정하지 않았다. 목록은 그대로 둔다

| 요즘 뜨는 촬영지 2편 | 팀이 고른 고정 목록 | 데이터에 있는지 확인 전 |

## 7. 범위 (v0 / v1)

- v0 (10/30 오전 첫 배포): 홈·검색(S1·E1·E2), 촬영지 목록(S2 시트 펼침 화면), 촬영지 상세(S3·S3 사진 없음·E3), 코스(S4). 지도 버튼 자리는 카카오맵 외부 링크 [제안]. 출처 문구만 넣고 정확도 라벨은 v1 이후
- v1 (10/31): 카카오 지도 SDK, S2의 3단계 시트, "지도로 보기" → S2, 지도 핀(스틸컷 프레임 모양 적용 제안), PC 지도 레이아웃
- S5(장소 상세)를 v0에 넣을지는 정하지 않았다. 코스 카드가 S5로 이어지므로 S4와 같은 시점에 만드는 것을 제안한다
- 2026-10-29 갱신: 1차 배포에 위 v0·v1 기능을 한 번에 넣고 v0/v1 구분은 더 쓰지 않는다(PRD 3장 기준). S4의 전체 경로 지도(새 화면 없음)와 S2의 근처 장소 핀(촬영지를 고를 때, 경로 지도와 분리)도 1차 배포에 넣는다
- 구·군 필터는 범위 밖이다

## 8. 예외와 상태

| 상황 | 화면의 처리 |
| --- | --- |
| 검색 결과 없음 | E2: 안내 + 요즘 뜨는 촬영지 2줄 |
| 촬영지 좌표 없음 | 핀 없음, 목록 맨 뒤에 "주소만 표시". 상세는 E3(주소 복사, 근처·코스 숨김) |
| 작품의 촬영지가 전부 좌표 없음 | 지도 없이 목록만 [제안] |
| 촬영지 사진 없음 | 사진 칸을 없애고 낮은 헤더(S3 사진 없음) |
| 포스터·연도·장르 없음 | 아이콘 타일, 없는 줄만 빠짐 |
| 줄거리·소개글 없음 | 칸 자체가 빠짐 |
| 코스 후보 부족 | 있는 곳만 보여주고 빈 카드를 만들지 않음 |

| 근처 장소 후보 없음 | 근처 핀을 그리지 않음, 안내 문구도 없음 [제안] |
| 지도 SDK 실패 | 목록·상세·코스 카드는 그대로, S4의 경로 지도와 근처 핀만 빠짐 |

**아직 그리지 않은 상태**
- 로딩(코스 만드는 중 문구는 네이밍 문서에 있음), 데이터 불러오기 실패, "주소 복사" 후 복사됨 안내
- S5의 식당·카페 변형
- E1의 키보드, 지도 SDK 로딩 실패
- S4의 전체 경로 지도, S2·PC 지도의 근처 장소 핀(2026-10-29에 범위에 넣음, 캔버스 반영 여부 확인 필요)

## 9. 측정 (제안)

- 과업: 작품 선택 → 촬영지 확인 → 근처에서 들를 곳 정하기
- S3 미리보기만으로 과업을 끝낼 수 있으므로, S4로 들어가는 비율이 곧 코스 발견율이다
- 소요 시간은 S1 진입부터 잰다

## 10. 결정 현황

**확정**
- 검색 결과는 별도 화면 없이 홈에서 고른다
- 코스는 상세에서 한 단계 더 들어가는 선택이다
- 작품 정보는 시트 머리말에 고정한다
- S2는 지도 중심 + 바텀시트(요청 1·3), S3 상단은 촬영지 사진(요청 4)
- 구·군 칩 삭제, 반응형 기준 768px, 홈 목록은 작품 2편 고정, 이용 조건·사진 출처 표기 없음
- 코스 카드는 눌러서 상세로 가고, S5를 만든다(요청 8)
- 전체 경로 지도는 S4 안에 둔다(새 화면 없음). 근처 장소 핀은 S2에서 촬영지를 고를 때 따로 띄우고 경로 지도와 섞지 않는다. 홈 라벨은 "요즘 뜨는 촬영지"로 통일한다(2026-10-29, 사용자 결정)

**열린 결정**
- 홈 2편이 촬영지 데이터에 있는지 확인, 한 줄을 작품 단위(S2로 이동)로 둘지 대표 촬영지 단위(S3로 이동)로 둘지
- 작품 포스터·연도·장르·줄거리의 출처(연결 여부)
- 촬영지 이미지 주소(나중에 요청)
- S5 출처 문구, S5의 v0 포함 여부
- 코스 순서 규칙, 거리 표기 단위(m/km)
- "같은 작품의 다른 촬영지" 칩의 유지 여부(제안 상태)
- 지도 위 근처 장소 핀을 눌러 S5로 갈 수 있게 할지(근처 미리보기 줄은 S5로 가기로 정함)
- 경로 지도의 높이와 핀·선 모양, 근처 장소 핀의 모양, 근처 핀이 보이게 확대할지, 선택을 푸는 방법, PC에서 코스 핀과 촬영지 번호 핀이 겹칠 때의 처리
- 목록 정렬 기준(촬영지 목록)
- 컬러·폰트 방향, 같은 이름의 서비스·상표·도메인 중복 확인(네이밍 문서의 미확인 항목)
