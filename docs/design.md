# 스틸스팟 (Still Spot) design.md

영화·드라마 속 촬영지를 지도에서 찾고, 근처 관광지·식당·카페까지 코스로 이어 보는 서비스의 디자인 기준 문서입니다. 1~4단계 질문(무드보드 → 컬러 → 서체 → 컴포넌트·말투)에서 정한 값만 담았고, 정하지 못한 것은 맨 아래 "미결·미확인"에 따로 적었습니다.

**읽는 법**
- 값이 서로 다르면 이 문서를 따릅니다. 단, 화면 구성·동작은 "와이어프레임 최종 명세", 문구 원문은 "스틸스팟 네이밍·콘셉트 결정"을 따릅니다.
- `[제안]`은 아직 사용자가 확정하지 않은 값입니다. 구현하면서 바꿀 수 있습니다.
- 대비 값은 WCAG 공식으로 직접 계산한 숫자입니다(라이트 / 다크 순서).

## 1. Overview

### 철학
정보는 담백하게, 필름은 세 곳에만.
핵심 과업이 "위치를 확인하고 갈 만한지 판단하는 것"이라서 질감을 넓게 깔지 않습니다. 장식 없이 큰 글자와 수치로 말하고, 영화의 질감은 정해 둔 자리에서만 나타납니다.

### 대표 키워드
1. **필름 질감** — 스틸컷 프레임 모양의 코너 마크. 번호 뱃지·빈 프레임·로딩/완성 순간에만 씁니다.
2. **담백한 정보** — 문구는 짧게, 정보는 라벨과 수치로(예: 촬영지 7곳 · 직선 320m).
3. **이어지는 경로** — 촬영지에서 근처 코스로 이어지는 흐름. 대표 카피 "영화 속 그 장소로 이어지는 길".

### 화면 원칙 (와이어프레임 명세 기준)
- 촬영지를 먼저 보여줍니다. 코스는 이어서 선택하는 기능이고 필수 단계가 아닙니다.
- 막다른 길을 만들지 않습니다. 결과가 없거나 좌표가 없어도 다음에 갈 곳을 남깁니다.
- 데이터가 없어도 화면이 성립합니다. 없는 칸은 비워 두지 않고 빠집니다.
- 화면 문구에 지역명을 쓰지 않습니다(출처 문구 제외).

### 형태·표면 규칙
| 항목 | 규칙 |
|---|---|
| 질감 | 배경·카드에 질감 이미지나 그레인을 쓰지 않음 |
| 필름 요소 | 번호 뱃지, 빈 사진·포스터 자리(빈 프레임), 로딩·완성 순간. 이 세 곳 외에는 쓰지 않음 |
| 반경 | 카드·시트 **16px**, 버튼·칩·입력창·알림 상자 **6px**, 필름 요소(번호 뱃지·핀·빈 프레임) **0px** |
| 층 구분 | 1px 선(헤어라인)으로만 나눔. 그림자·그라데이션 없음 |
| 버튼 위계 | 채움 버튼은 화면당 1개, 나머지는 고스트. 버튼에는 포인트 색을 쓰지 않음 |
| 피할 인상 | 관공서 포털 느낌. 표 형태의 나열과 진한 단색 헤더 바를 쓰지 않음 |
| 테마 | 라이트·다크 둘 다 제공. 값은 두 벌, 컴포넌트는 한 벌 |
| 지도 | 두 모드 모두 밝은 타일로 고정(카카오 지도 다크 지원은 웹 SDK에서 직접 확인하지 못함). 핀과 선택 색도 한 벌 |

### 적용 범위
- 모바일 기준 폭 390px. 폰 폭 360px에서 글 영역은 328px(좌우 여백 16px)입니다.
- 767px 이하는 모바일 화면 그대로, 768px 이상은 왼쪽 목록 패널 + 지도 + 지도 위 상세 패널. 홈·검색은 PC에서도 가운데 한 칸 최대 480px.
- 누르는 영역은 모두 44px 이상.

## 2. Color Palette

색은 **토큰 이름으로만** 참조합니다. 컴포넌트에 색 값을 직접 쓰지 않습니다.

### 토큰
| 구분 | 토큰 | 라이트 | 다크 | 역할 |
|---|---|---|---|---|
| Primary | `ink` | `#1A1917` | `#F2F0EC` | 본문 글자, 채움 버튼 배경, 선택 막대, 키보드 포커스 선 |
| Secondary | `accent` (구리) | `#9D5113` | `#E78739` | **숫자 전용**: 번호, 직선 거리, "촬영지 N곳"의 N |
| Neutral | `canvas` | `#F6F5F2` | `#121110` | 화면 바탕, 채움 버튼 위 글자색 |
| Neutral | `soft` | `#ECEAE5` | `#1E1C19` | 눌림·선택 배경, 안내 상자, 분류 칩 배경 |
| Neutral | `hair` | `#DCD9D3` | `#2C2A26` | 장식 구분선(목록 줄 사이, 카드 테두리), 눌린 줄·카드 안의 분류 칩 배경 |
| Neutral | `hair-s` | `#85817A` | `#726E66` | 조작 요소의 경계(고스트 버튼·칩·검색창·아이콘 버튼), 시트 윗선, 타임라인 연결선. 배경 대비 3:1 이상 |
| Neutral | `sub` | `#5E5A53` | `#A8A49C` | 보조 글자(주소, 보조 줄, 안내 문구), 눌린 채움 버튼 배경 |
| Neutral | `dis` | `#9A958C` | `#5A564F` | 비활성 글자·아이콘 |
| Semantic | `error` | `#B42318` | `#FF7B6B` | 오류 아이콘 하나에만 사용 |

지도 위 고정 색(모드와 상관없음): 지도 타일 약 `#ECEBE7`, 핀 바탕 `#FFFFFF`, 핀 글자·코너 마크 `#1A1917`, 선택된 핀 바탕 `#1A1917`·글자 `#FFFFFF`.

의미 색은 오류 하나뿐입니다. 성공·정보·주의는 색을 쓰지 않고 문구와 모양으로 구분합니다.

### 토큰 코드
```css
:root {
  --canvas: #F6F5F2; --soft: #ECEAE5; --hair: #DCD9D3; --hair-s: #85817A;
  --ink: #1A1917;    --sub: #5E5A53;  --dis: #9A958C;
  --accent: #9D5113; --error: #B42318;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --canvas: #121110; --soft: #1E1C19; --hair: #2C2A26; --hair-s: #726E66;
    --ink: #F2F0EC;    --sub: #A8A49C;  --dis: #5A564F;
    --accent: #E78739; --error: #FF7B6B; color-scheme: dark;
  }
}
:root[data-theme="dark"] {
  --canvas: #121110; --soft: #1E1C19; --hair: #2C2A26; --hair-s: #726E66;
  --ink: #F2F0EC;    --sub: #A8A49C;  --dis: #5A564F;
  --accent: #E78739; --error: #FF7B6B; color-scheme: dark;
}
```

### 글자·경계 대비 (계산값)
기준: 글자 4.5:1, 아이콘·경계선 3:1.

| 조합 | canvas 위 | soft 위 |
|---|---|---|
| `ink` 글자 | 16.11 / 16.57 | 14.61 / 14.94 |
| `sub` 글자 | 6.29 / 7.59 | 5.70 / 6.84 |
| `accent` 숫자 | 5.32 / 7.12 | 4.83 / 6.41 |
| `error` 아이콘·글자 | 6.03 / 7.45 | 5.47 / 6.72 |
| `hair-s` 경계 | 3.55 / 3.72 | 3.22 / 3.35 |

- 채움 버튼 글자(canvas on ink) 16.11 / 16.57. 눌린 채움 버튼 글자(canvas on sub) 6.29 / 7.59.
- 검색창 안내 문구는 `sub`(6.29 / 7.59)를 씁니다. `dis`는 쓰지 않습니다.
- `dis`는 canvas 위 2.73 / 2.59라서 눌러도 반응 없음이 보이는 수준입니다. 비활성 컨트롤은 WCAG 글자 대비 적용 대상이 아닙니다.
- `soft`와 `canvas`의 면 차이는 1.10 / 1.11로 작습니다. 그래서 **선택**에는 면 외에 왼쪽 2px 막대를 함께 씁니다.
- 라이트 시트(`canvas`)와 지도 타일의 면 차이는 1.09입니다. 시트 윗선 `hair-s`가 타일 위에서 3.25 / 4.25로 구분을 맡습니다.

### 색 사용 규칙
1. `accent`는 숫자에만 씁니다. 버튼 윤곽, 칩 채움, 연결선, 링크에는 쓰지 않습니다.
2. 채움(ink) 버튼은 화면당 1개입니다.
3. 층은 `hair`(장식)와 `hair-s`(조작 요소) 두 단계의 1px 선으로만 나눕니다.
4. 오류는 색만으로 전달하지 않습니다. 삼각형 아이콘 + 문구를 함께 씁니다.
5. 눌림·선택·비활성 상태를 만들 때도 새 색을 만들지 않고 위 토큰만 조합합니다.
6. 지도는 모드별로 바꾸지 않습니다.

## 3. Typography

### 서체
- 본문과 모든 화면 글자는 **Pretendard Variable**(SIL OFL 라이선스). 굵기는 **400과 700 두 단계만** 씁니다. 500·600은 쓰지 않습니다.
- 영문 워드마크 **"STILL-SPOT"** 한 곳만 **Michroma**(Google Fonts)를 씁니다. Michroma에는 굵기가 400 하나뿐이라 굵게 하지 않습니다(굵게 지정하면 글자를 억지로 두껍게 만든 가짜 굵기가 됩니다). 영문 서체는 이 한 곳 외에는 쓰지 않고, 작품명 같은 데이터 속 영문도 Pretendard로 둡니다.
- 폴백(본문): `"Pretendard Variable", Pretendard, system-ui, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 폴백(워드마크): `Michroma, "Pretendard Variable", Pretendard, system-ui, sans-serif`
- 불러오기: 글자 조각(unicode-range)으로 나눈 dynamic-subset 방식을 권장합니다. 조각 92개, 전체 약 2.96MB이고 화면에 쓰는 글자 조각만 받습니다.
- Michroma 불러오기: `https://fonts.googleapis.com/css2?family=Michroma&text=STILL-SPOT&display=swap`. `text` 값으로 글자 `STILL-SPOT` 9종만 받아 용량이 아주 작습니다(2026-10-29에 내려받기 확인). 워드마크 글자를 바꾸거나 다른 영문에 쓰려면 `text` 값을 고치거나 지워야 합니다.
- 모노 서체는 쓰지 않습니다. 숫자도 Pretendard입니다.

### 크기 단계
| 단계 | 크기 / 줄 높이 | 굵기 | 자간 | 쓰는 곳 |
|---|---|---|---|---|
| Display | 28 / 36 | 700 | −0.02em | 홈 큰 문구(대표 카피), 촬영지명·장소명 |
| Title | 20 / 28 | 700 | −0.01em | 시트 작품명, 결과 없음 제목, 코스 제목 |
| Body | 16 / 24 | 400 · 700 | 0 | 700: 목록의 작품명·촬영지명, 버튼, 소제목 / 400: 본문, 관련 장소 이름 |
| Sub | 14 / 22 | 400 | 0 | 주소, 보조 줄(촬영지 N곳, 직선 거리), 이동·정보 칩, 부제, 안내 상자 |
| Micro | 12 / 18 | 400 | 0 | 출처 문구, 라벨, 분류 칩 |
| Num | 11 / 16 | 700 | 0 | 핀·목록 번호(코너 마크 안) |
| Wordmark | 14 / 22 | 400 (Michroma, 단일 굵기) | 0 | 홈 상단과 PC 상단바의 서비스명 "STILL-SPOT"(앞에 로고 심볼, 4-14). 한 줄, 줄바꿈 없음 |

- 자간은 em 단위입니다. 28px에서 −0.02em은 −0.56px입니다. 14px 이하는 조였을 때의 읽기 쉬움을 확인하지 못해 0으로 둡니다.
- 크기는 px로 적고 구현은 rem(16px = 1rem)으로 환산합니다. 폰의 글자 크기 설정이 어느 정도 반영되는지는 확인하지 못했습니다.
- 대표 카피("영화 속 그 장소로 이어지는 길", 28px)는 한 줄 폭이 314.0px로 328px 글 영역에 14.0px 여유가 남습니다(자간 0이면 323.5px, 여유 4.5px).
- 촬영지명 줄 높이 36px 기준으로 촬영지 상세(S3) 첫 화면 고정 항목 합계는 678px, 844px 화면에서 남는 높이 166px, 섹션 간격 7곳은 각각 23px 이하입니다(소제목 영역 높이는 추정).

### 숫자
- 숫자 요소만 `accent` 색 + 700 + `font-variant-numeric: tabular-nums`(숫자 폭을 같게)로 씁니다.
- 단위와 라벨(곳, m, km)은 주변 글자색 그대로입니다.
- **문장 전체에 tabular-nums를 켜지 않습니다.** 켜면 대표 카피 폭이 323.5px에서 328px로 늘어 글 영역 한계에 닿습니다.
- 거리·숫자 열은 오른쪽 맞춤 + tabular-nums.

### 줄바꿈·정렬
| 대상 | 규칙 | CSS |
|---|---|---|
| 모든 한글 | 띄어쓰기 단위로 끊고, 넘칠 때만 글자 단위로 끊음 | `word-break: keep-all; overflow-wrap: anywhere` |
| Display · Title | 줄 길이를 고르게 | `text-wrap: balance` (Chrome·Edge 114, Firefox 121, Safari 17.5 이상, 6줄 이하일 때만) |
| 목록의 작품명·촬영지명 | 두 줄까지, 넘치면 말줄임(…) | `-webkit-line-clamp: 2` |
| 상세·시트의 이름, 주소 | 줄 수 제한 없이 전부 표시(주소는 복사 기능이 있어 잘리면 안 됨) | 말줄임 없음 |
| 텍스트 정렬 | 모두 왼쪽 정렬. 가운데 정렬은 버튼 글자만 | `text-align: left` |

## 4. UI Components

### 4-1. 상태 표현 (모든 컴포넌트 공통)
상태를 색으로 구분하지 않고 **배경을 한 단계 옮겨서** 표현합니다.

| 상태 | 표현 |
|---|---|
| 기본 (Default) | 컴포넌트별 기본 모양 |
| 눌림 (Active) | 배경 `soft`. 채움 버튼만 배경 `sub` |
| 선택 (Selected) | 목록 줄에만 씁니다. 배경 `soft` + 왼쪽 2px `ink` 막대(지도에서 고른 핀과 같은 줄) |
| 비활성 (Disabled) | 글자·아이콘 `dis`. 채움 버튼은 배경·테두리 `soft` + 글자 `dis`, 고스트 버튼은 테두리 `hair` + 글자 `dis` |
| 포커스 (Focus, 키보드) | 2px `ink` 외곽선을 2px 띄워서 표시. 모든 상태 위에 겹침. 검색창만 아래 별도 규칙 |

- 눌림·선택 상태의 이름·주소·구리색 숫자는 모두 4.5:1 이상입니다(구리색 4.83 / 6.41).
- 데이터가 없어서 누를 수 없는 버튼은 비활성이 아니라 **숨깁니다**(좌표 없는 촬영지의 E3 화면). 비활성은 곧 누를 수 있게 되는 일시적인 경우에만 씁니다. `[제안]` 와이어프레임에서 비활성이 필요한 곳은 아직 없습니다.
- PC 마우스 올림(hover)은 눌림과 같은 표현을 쓰고 터치 기기에서는 끄는 것(`@media (hover: hover)`)을 제안합니다. `[제안]`

### 4-2. 버튼
| 종류 | 크기 · 반경 | 모양 | 눌림 | 비활성 |
|---|---|---|---|---|
| 채움 | 높이 52px · 6px | 배경 `ink`, 글자 `canvas` Body 700, 가운데 정렬 | 배경 `sub` | 배경·테두리 `soft`, 글자 `dis` |
| 고스트 | 높이 52px · 6px | 투명 배경, 1px `hair-s` 테두리, 글자 `ink` Body 700 | 배경 `soft` | 테두리 `hair`, 글자 `dis` |

## 5. Tone & Voice

### 문체
차분한 해요체. 짧은 문장, 정보는 명사형 라벨과 수치로.

### 말투 규칙
1. 차분한 해요체로, 한 문장은 짧게 씁니다. 이모지와 유행어(핫플, 인생샷, 힐링)는 쓰지 않습니다.
2. 정보는 명사형 라벨과 수치로 씁니다. 예: 촬영지 7곳 · 직선 320m
3. 영화 용어(컷, 장면, 엔딩 등)는 한 화면에 하나만, 은유로 씁니다.
4. 느낌표와 반말은 "찾았다!" 한 곳(코스 완성 순간)에서만 씁니다.
5. 출처·오류 안내는 사실 그대로 씁니다. 영화 용어나 장난스러운 톤을 섞지 않고, "정확하게" 같은 정확도 표현도 쓰지 않습니다(좌표 없는 촬영지가 있음).
6. 오류와 빈 상태는 "무슨 일 + 다음에 할 일"로 씁니다. 원인을 하나로 단정하지 않고 이어서 갈 곳을 남깁니다. `[제안]`
7. 화면 문구에 지역명을 쓰지 않습니다. 출처 문구에서만 지역명을 씁니다.
8. 숫자와 단위는 붙여 쓰고(12곳, 320m), 라벨과 숫자 사이만 띄웁니다(촬영지 12곳). `[제안]`
9. 버튼은 가는 곳이나 하는 일을 짧게 씁니다. `[제안]`

### 숫자·거리 표기
- 직선 거리는 항상 "직선"을 앞에 붙입니다(좌표로 계산한 직선 거리라서).
- 1km 미만은 m(10m 단위로 반올림), 1km 이상은 km(소수 첫째 자리). 예: 320m, 1.2km. 10m 단위로 반올림해서 주소 변환 오차보다 정밀해 보이지 않게 합니다.
- 반올림한 값이 1,000m 이상이면 km로 넘깁니다(995m 이상은 1.0km).
- "분류 · 직선 N" 순서로 씁니다(확정). 예: 관광지 · 직선 320m. 네이밍 문서의 예시("직선 320m · 관광지")와 순서가 다르며, 이 문서의 순서를 따릅니다.

## 6. 미결·미확인

### 정하지 못한 것
- 간격(spacing) 토큰: 목록 줄 높이와 S3 섹션 간격 상한(23px 이하) 외에는 정하지 않았습니다.
- 식당·카페 타일의 아이콘 모양.
- 데이터 불러오기 실패·주소 복사 후 토스트의 확정 문구, 토스트 표시 시간, 선택된 핀 이름표 규격.
- 근처 장소 핀의 크기·모양·이름표, 코스 경로선의 색(지도는 모드와 상관없이 밝은 타일이라 모드별로 바뀌는 `hair-s` 대신 지도 고정 색을 써야 하는지), S4 경로 지도의 높이(약 200px 제안), PC에서 코스 번호 핀과 촬영지 번호 핀이 겹칠 때의 표현.
- PC hover 표현 확정, 로딩 모션의 반복 시간(1.8초)·맞물림 시간(0.5초) 확정.

### 확인하지 못한 것
- 실기기에서 11~14px 글자의 읽기 쉬움, 28px 조임의 모습, 야외 밝기에서 `soft` 배경의 구분, 14px Michroma 워드마크(폭이 넓은 서체)의 읽기 쉬움. 워드마크는 `ink` 색에서 대비 16.11 / 16.57(계산값, 글자 4.5:1 기준 충족)입니다.
- Michroma의 라이선스 조건(Google Fonts 제공 서체라 SIL OFL로 알고 있으나 서체 페이지에서 직접 확인하지 못함).
- 카카오 지도 타일 위 `hair-s` 경계선과 코스 경로선·근처 장소 핀의 실제 모습, 카카오 웹 SDK의 다크 지도 미지원 여부(직접 확인 못함).
- iPhone Safari의 2줄 말줄임 표시, rem 사용 시 폰 글자 크기 설정의 반영 정도.
- 실제 데이터(작품 428개, 촬영지 2,193건)에서 가장 긴 이름과 띄어쓰기 없는 이름의 길이, 촬영지–관광지 직선 거리의 분포.
- 2px→1px 검색창이 입력 자리로 읽히는 정도(사용성 테스트 없음), 색을 구분하기 어려운 사람의 오류 아이콘 인식.
- 한글 입력 중 검색창의 실제 모습, 로딩 문구가 실제로 보이는 시간(AI 호출 소요 시간).
- 같은 이름의 기존 서비스·상표·도메인 중복 여부.
